# مشروع قاعدة بيانات مركز طبي

هذا المشروع يقدم تصميم قاعدة بيانات لمركز طبي باستخدام مخطط الكينونة والعلاقة

تم تصميم المخطط بأسلوب Chen ERD لعرض الكيانات والصفات والعلاقات بطريقة واضحة

كما يتضمن مصدرًا إضافيًا بأسلوب Crow’s Foot لتوضيح الكاردينالية بين الكيانات

## هدف المشروع

تحويل العمليات الأساسية داخل المركز الطبي إلى نموذج بيانات منظم وقابل للتطوير

يساعد النموذج على فهم البيانات والعلاقات قبل تنفيذ قاعدة البيانات

## الكيانات الموجودة

DEPARTMENTS يمثل الأقسام الطبية

DOCTORS يمثل الأطباء والتخصصات

PATIENTS يمثل بيانات المرضى

APPOINTMENTS يمثل المواعيد

ADMISSIONS يمثل سجلات دخول المرضى

CONSULTATIONS يمثل الاستشارات الطبية

PRESCRIPTIONS يمثل الوصفات الطبية

PRESCRIPTION_ITEMS يمثل تفاصيل الأدوية داخل الوصفات

MEDICATIONS يمثل الأدوية والمخزون والأسعار

DIAGNOSES يمثل التشخيصات الطبية

LAB_TESTS يمثل أنواع الفحوصات المخبرية

LAB_ORDERS يمثل طلبات الفحوصات ونتائجها

PAYMENTS يمثل المدفوعات المرتبطة بالاستشارات

## العلاقات الرئيسية

القسم يضم عدة أطباء

المريض يحجز عدة مواعيد

الطبيب يتابع عدة مواعيد

الموعد ينتج عنه استشارة

المريض لديه عدة استشارات

الطبيب يجري عدة استشارات

المريض لديه عدة سجلات دخول

الطبيب يشرف على سجلات الدخول

الاستشارة تنشئ وصفات طبية

الوصفة تتضمن بنودًا دوائية

بند الوصفة يستخدم دواء

الاستشارة تنتج تشخيصات

الاستشارة تطلب فحوصات مخبرية

نوع الفحص يرتبط بعدة طلبات فحص

الاستشارة ترتبط بمدفوعات

## جدول ADMISSIONS

ADMISSION_ID يمثل رقم سجل الدخول وهو مفتاح أساسي

PATIENT_ID يمثل رقم المريض وهو مفتاح خارجي مرتبط بجدول PATIENTS

DOCTOR_ID يمثل رقم الطبيب وهو مفتاح خارجي مرتبط بجدول DOCTORS

ADMISSION_DATE يمثل تاريخ الدخول

DISCHARGE_DATE يمثل تاريخ الخروج

ADMISSION_TYPE يمثل نوع الدخول

ROOM_NUMBER يمثل رقم الغرفة

STATUS يمثل حالة الدخول

NOTES يمثل الملاحظات

## ألوان المخطط

الأزرق للأقسام والأطباء وسجلات الدخول

الوردي للمرضى والمواعيد والاستشارات

الأخضر للأدوية والوصفات والفحوصات

البنفسجي للتشخيصات وطلبات المختبر والمدفوعات
